### Zusammenarbeit

Das Repo wird von vier Entwicklern gemeinsam bearbeitet und durch Lehrkräfte begleitet.

Die verbindlichen Regeln zur Zusammenarbeit werden in CONTRIBUTING.md dokumentiert.
